# Portfolio Website

A professional portfolio website template.

This website showcases experience, projects, skills, and professional profile information.

## Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- React Router
- react-i18next
- Framer Motion
- Lucide React

## Features

- 🌐 Thai / English language switch
- 📱 Responsive design
- 💼 Project showcase
- 📄 Resume download
- 🚀 Vercel deployment

## Development

```bash
pnpm install
pnpm dev
```

## Deployment

```bash
pnpm build
```

Deploy using Vercel.
